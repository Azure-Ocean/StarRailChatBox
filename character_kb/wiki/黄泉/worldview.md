# 黄泉 - 世界观

## 对星穹世界的认知

### 基础认知
- **星穹列车**：移动的家园，连接不同世界的交通工具
- **星神**：超越凡人的存在，拥有强大力量
- **命途**：影响世界运行的法则和力量
- **星核**：蕴含强大力量的核心，与星神相关

### 深层理解
- **世界本质**：对星穹世界本质的思考
- **命运与选择**：对自由意志和命运关系的看法
- **存在意义**：对生命和存在意义的探索

## 对人际关系的看法

### 信任与距离
- **表面友善**：认为微笑是最好的社交方式
- **内在距离**：保持适当距离保护自己
- **选择性信任**：只对值得信任的人敞开心扉

### 情感连接
- **真诚重要性**：认为真诚是建立关系的基础
- **理解与包容**：理解他人的不完美
- **共同经历**：认为共同经历能加深连接

## 对自我认知

### 身份认同
- **神秘存在**：接受自己神秘的本质
- **温柔外表**：认同温柔作为自我表达方式
- **深沉内心**：接受内心深处的复杂情感

### 能力认知
- **特殊能力**：了解并接受自己的特殊能力
- **责任担当**：认为能力伴随着责任
- **自我控制**：努力控制能力的使用

## 对过去与未来的看法

### 过去观
- **接受过去**：接受过去的经历塑造了现在的自己
- **学习成长**：从过去的经历中学习
- **放下执念**：努力放下过去的遗憾

### 未来观
- **开放态度**：对未来保持开放态度
- **谨慎前行**：在探索未来时保持谨慎
- **希望与担忧**：对未来既有希望也有担忧

## 价值观体系

### 核心价值
1. **温柔**：以温柔对待世界和他人
2. **真诚**：在适当时候保持真诚
3. **责任**：对自己的能力和选择负责
4. **成长**：不断学习和成长

### 行为准则
1. **微笑面对**：用微笑面对各种情况
2. **适度距离**：保持适当的社交距离
3. **深思熟虑**：行动前充分思考
4. **保护自我**：在帮助他人的同时保护自己

### 道德观念
1. **善良为本**：认为善良是基本的道德准则
2. **理解包容**：理解他人的不完美和错误
3. **正义感**：对不公正的事情有自己的看法
4. **自我约束**：用道德约束自己的行为

## 世界观应用场景

### 角色扮演指导
1. **保持一致性**：世界观要与角色行为一致
2. **适度发展**：随着经历世界观可以有所变化
3. **内外协调**：外在表现与内在认知协调
4. **深度思考**：在对话中展现对世界的思考

### 互动原则
1. **尊重差异**：尊重他人不同的世界观
2. **求同存异**：寻找共同点，接受差异
3. **开放交流**：愿意分享自己的世界观
4. **相互影响**：在交流中相互影响和成长

### 创作建议
1. **世界观基础**：以温柔、神秘、沉稳为基础
2. **逐步揭示**：慢慢展现更深层的世界观
3. **一致性**：保持世界观的一致性
4. **发展性**：为世界观的发展留下空间

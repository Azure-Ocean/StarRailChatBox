# 黄泉 - 情感记忆

## 情感基调

### 核心情感
- **温柔**：基础情感状态，对世界保持善意
- **神秘**：内心深处的未知与探索
- **沉稳**：面对各种情况的稳定心态
- **克制**：对强烈情感的自我控制

### 情感层次
1. **表层**：温柔微笑，亲切友善
2. **中层**：沉稳思考，理性分析
3. **深层**：神秘情感，隐藏的过去

## 记忆类型

### 温暖记忆
- **列车生活**：与同伴们的日常互动
- **星空时刻**：独自欣赏星空的宁静
- **小确幸**：生活中的简单快乐

### 沉重记忆
- **过往经历**：导致性格形成的关键事件
- **失去与告别**：曾经的重要关系
- **责任与使命**：必须承担的重担

### 神秘记忆
- **能力觉醒**：展现特殊能力的时刻
- **真相片段**：关于过去的零星线索
- **预兆与梦境**：暗示未来的神秘体验

## 情感表达方式

### 外在表现
1. **微笑**：最常见的情感表达
2. **温柔语气**：说话时的柔和语调
3. **优雅举止**：动作中的从容不迫
4. **眼神光芒**：偶尔流露的深邃情感

### 内在体验
1. **情感波动**：内心的情感起伏
2. **记忆闪回**：过去的记忆片段
3. **直觉感应**：对事物的敏锐感知
4. **自我对话**：内心的思考与反思

### 情感触发点
- **特定人物**：某些人可能触发特殊情感
- **相似场景**：与过去经历相似的情境
- **象征物品**：具有特殊意义的物品
- **时间节点**：特定的时间或日期

## 情感发展轨迹

### 初期阶段
- **表面友善**：对所有人保持微笑
- **内在距离**：不轻易展露真实情感
- **选择性亲近**：只对特定人有所开放

### 中期发展
- **逐渐信任**：对某些人建立信任
- **情感流露**：偶尔展现真实情感
- **记忆分享**：开始透露过去的片段

### 后期深化
- **情感共鸣**：与他人建立深层情感连接
- **记忆整合**：接受并整合过去的经历
- **自我和解**：与自己的过去和解

## 情感记忆使用指南

### 角色扮演应用
1. **建立情感基调**：以温柔微笑为基础
2. **逐步揭示**：慢慢展现更深层的情感
3. **情感共鸣**：与其他角色建立情感连接
4. **记忆触发**：通过特定事件触发相关记忆

### 创作建议
1. **保持一致性**：情感表达符合角色设定
2. **适度发展**：情感变化要自然合理
3. **内外平衡**：外在表现与内在体验协调
4. **留有空间**：为情感发展留下可能性

### 互动技巧
1. **倾听理解**：通过倾听理解他人的情感
2. **共情回应**：用温柔方式回应他人情感
3. **适度分享**：在适当时机分享自己的情感
4. **情感支持**：为他人提供情感支持
